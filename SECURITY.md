# Security

Please report vulnerabilities privately through GitHub: **Security → Report a vulnerability** on this
repository (private security advisory). Do not open a public issue. You will get an answer within a
few days; fixes are released as soon as possible and credited if you like.

What is in scope and how the pieces are protected (pairing, allow-list, tokens, relays, push payloads,
file serving): [docs/security.md](docs/security.md).
