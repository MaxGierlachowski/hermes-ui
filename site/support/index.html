What you need

  • Hermes Agent running on your computer (the desktop app, or hermes gateway run).
  • Node.js 24 or newer on the same computer.
  • The hermes-ui backend from the project on GitHub, free and open source.
  • The app on your phone. No account anywhere.

Step-by-step guide: Self-hosting guide. The short version:

  1. git clone https://github.com/MaxGierlachowski/hermes-ui.git && cd hermes-ui && npm install
  2. HERMES_UI_REMOTE=iroh npm start starts the backend with remote access over iroh.
  3. npx hermes-ui pair prints a QR code.
  4. In the app: Scan QR code. Done.

Frequently asked questions

Can I try the app without a backend?

Yes. Tap Try the demo on the first screen. The app then runs on sample data generated on the device, including streamed replies, an approval, a question, coding agents and the inbox. Nothing is sent anywhere. Leave it with the Demo · exit badge in the header or in Settings.

How does pairing work?

The QR code of hermes-ui pair (or Remote access → Pair device in the web interface on your computer) contains your backend's address and a one-time code. You can also paste the link into the field on the pairing screen, or open it on the phone. The code is valid for a few minutes and only once; if pairing fails, create a new one.

After pairing, your backend admits only your paired devices. You can revoke a device in the remote-access dialog on your computer.

Is the connection secure? Do I need to open a port?

No port needs to be opened. The app and your backend connect end-to-end encrypted over iroh (QUIC with TLS 1.3): directly when possible, otherwise through a relay that only forwards encrypted packets. By default your backend uses n0's public relays; you can run your own relay instead (IROH_RELAY_URL). Details in the privacy policy.

The app says “Not connected” or keeps connecting
  • Is the backend running with remote access? npx hermes-ui status on your computer shows the backend, remote and device state.
  • Was the device revoked, or the backend's data directory reset? Then pair again (Settings → Forget connection, then scan a new code).
  • Some networks (company Wi-Fi, some mobile carriers) block UDP. The app then uses the relay; if that is blocked too, try another network.
  • The app shows the last state from its cache while offline (“as of …”) and reconnects by itself.
The connection is slow

Settings shows the current path: direct or relay. On the same Wi-Fi the connection should be direct. On iOS, allow Local Network for the app (iOS Settings → Privacy & Security → Local Network). Some routers prevent direct paths; a relay close to you (or your own) helps.

I don't get notifications
  • Allow notifications for the app in the system settings, and check the notification options in the app's Settings.
  • The app notifies while it is running. Android stops apps in the background within seconds: turn on Settings → Stay connected in the background (“While Hermes works” or “Always”). A quiet ongoing notification then keeps the connection open. If notifications still stop, exempt the app from battery optimisation.
  • On iOS, notifications arrive while the app is open or was just used; iOS suspends apps in the background.
  • Push with the app closed needs your own Firebase project and a self-built app; see the app README.
Images or voice messages don't work
  • Allow camera, microphone or photos when the app asks (or later in the system settings).
  • Voice messages are transcribed by Hermes Agent itself; speech-to-text must be set up there.
  • Images that agents reference by a local path are only shown from allowed folders (HERMES_UI_IMAGE_ROOTS on the backend).
What are the Paseo agents?

If you use the Paseo coding-agent app, the board shows the agents a Hermes chat started, with read-only transcripts, and lets you answer their permission requests from the inbox. Without Paseo this part simply stays empty.

What data does the app collect?

None for the developer: no account, no analytics, no ads, no tracking. Your data goes only between your phone and your own backend. See the privacy policy.

Is this an official Hermes Agent app?

No. It is an independent open-source project and not affiliated with, endorsed by or sponsored by Nous Research.

Reporting a problem

Open an issue on GitHub and include:

  • the app version (bottom of Settings) and your phone's system version,
  • the backend version and what npx hermes-ui status reports,
  • what you did, what you expected and what happened; screenshots help.

Never post pairing links, QR codes, tokens or the contents of .env or the backend's data directory: they grant access to your backend.

Security issues please report privately through GitHub's private vulnerability reporting.
