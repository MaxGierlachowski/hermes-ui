Ein mobiler Client für Hermes Agent, den du selbst hostest: jeder Hermes-Chat als Karte auf einem Live-Board, mit Antworten in Echtzeit, Freigaben, Rückfragen und einer Inbox. Open Source (MIT). Inoffiziell: keine Verbindung zu Nous Research und nicht von Nous Research unterstützt.

Was du brauchst

  • Hermes Agent auf deinem Rechner (die Desktop-App oder hermes gateway run).
  • Node.js 24 oder neuer auf demselben Rechner.
  • Das hermes-ui-Backend aus dem Projekt auf GitHub, kostenlos und quelloffen.
  • Die App auf deinem Handy. Ein Konto brauchst du nirgends.

Schritt für Schritt: Anleitung zum Selbst-Hosten (Englisch). Kurzfassung:

  1. git clone https://github.com/MaxGierlachowski/hermes-ui.git && cd hermes-ui && npm install
  2. HERMES_UI_REMOTE=iroh npm start startet das Backend mit Fernzugriff über iroh.
  3. npx hermes-ui pair zeigt einen QR-Code.
  4. In der App: QR-Code scannen. Fertig.

Häufige Fragen

Kann ich die App ohne Backend ausprobieren?

Ja. Tipp auf dem ersten Bildschirm auf Demo ansehen. Die App läuft dann mit Beispieldaten, die auf dem Gerät entstehen – mit Antworten in Echtzeit, einer Freigabe, einer Rückfrage, Coding-Agenten und der Inbox. Dabei wird nichts gesendet. Beenden kannst du die Demo über das Abzeichen Demo · beenden oben oder in den Einstellungen.

Wie funktioniert das Koppeln?

Der QR-Code von hermes-ui pair (oder Fernzugriff → Gerät koppeln in der Weboberfläche auf deinem Rechner) enthält die Adresse deines Backends und einen Einmal-Code. Du kannst den Link auch ins Feld auf dem Kopplungsbildschirm einfügen oder ihn auf dem Handy öffnen. Der Code gilt nur ein paar Minuten und nur einmal; klappt das Koppeln nicht, erzeug einfach einen neuen.

Danach lässt dein Backend nur noch gekoppelte Geräte zu. Im Fernzugriff-Dialog auf deinem Rechner kannst du ein Gerät jederzeit wieder entfernen.

Ist die Verbindung sicher? Muss ich einen Port öffnen?

Einen Port musst du nicht öffnen. App und Backend verbinden sich Ende-zu-Ende-verschlüsselt über iroh (QUIC mit TLS 1.3): direkt, wenn es geht, sonst über ein Relay, das nur verschlüsselte Pakete weiterreicht. Standardmäßig nutzt dein Backend die öffentlichen Relays von n0; du kannst stattdessen ein eigenes Relay betreiben (IROH_RELAY_URL). Mehr dazu in der Datenschutzerklärung.

Die App zeigt „Nicht verbunden“ oder verbindet sich endlos
  • Läuft das Backend mit Fernzugriff? npx hermes-ui status auf deinem Rechner zeigt Backend, Fernzugriff und Geräte.
  • Wurde das Gerät entfernt oder das Datenverzeichnis des Backends zurückgesetzt? Dann neu koppeln (Einstellungen → Verbindung vergessen, danach einen neuen Code scannen).
  • Manche Netze (Firmen-WLAN, einige Mobilfunkanbieter) sperren UDP. Dann nimmt die App das Relay; ist auch das gesperrt, probier ein anderes Netz.
  • Offline zeigt die App den letzten Stand aus dem Cache („Stand …“) und verbindet sich von selbst neu.
Die Verbindung ist langsam

In den Einstellungen siehst du den aktuellen Weg: direkt oder Relay. Im selben WLAN sollte die Verbindung direkt sein. Unter iOS erlaube der App das Lokale Netzwerk (iOS-Einstellungen → Datenschutz & Sicherheit → Lokales Netzwerk). Manche Router verhindern direkte Wege; ein Relay in deiner Nähe (oder ein eigenes) hilft.

Ich bekomme keine Benachrichtigungen
  • Erlaube der App Mitteilungen in den Systemeinstellungen und prüf die Benachrichtigungsoptionen in den Einstellungen der App.
  • Die App benachrichtigt, solange sie läuft. Android stoppt Apps im Hintergrund nach wenigen Sekunden: Schalte Einstellungen → Im Hintergrund verbunden bleiben ein („Während Hermes arbeitet“ oder „Immer“). Eine dezente Daueranzeige hält dann die Verbindung offen. Bleiben die Benachrichtigungen trotzdem aus, nimm die App von der Akku-Optimierung aus.
  • Unter iOS kommen Benachrichtigungen, solange die App offen ist oder gerade benutzt wurde; iOS pausiert Apps im Hintergrund.
  • Push bei geschlossener App braucht ein eigenes Firebase-Projekt und eine selbst gebaute App; siehe README der mobilen App (Englisch).
Bilder oder Sprachnachrichten funktionieren nicht
  • Erlaube Kamera, Mikrofon oder Fotos, wenn die App fragt (oder später in den Systemeinstellungen).
  • Sprachnachrichten transkribiert Hermes Agent selbst; die Spracherkennung muss dort eingerichtet sein.
  • Bilder, auf die Agenten mit einem lokalen Pfad verweisen, zeigt das Backend nur aus freigegebenen Ordnern (HERMES_UI_IMAGE_ROOTS).
Was sind die Paseo-Agenten?

Wenn du die Coding-Agenten-App Paseo nutzt, zeigt das Board die Agenten, die ein Hermes-Chat gestartet hat, mit Transkripten zum Mitlesen, und du kannst ihre Berechtigungsanfragen aus der Inbox beantworten. Ohne Paseo bleibt dieser Teil einfach leer.

Welche Daten erhebt die App?

Für den Entwickler keine: kein Konto, keine Analyse, keine Werbung, kein Tracking. Deine Daten gehen nur zwischen deinem Handy und deinem eigenen Backend hin und her. Mehr in der Datenschutzerklärung.

Ist das eine offizielle App von Hermes Agent?

Nein. Es ist ein unabhängiges Open-Source-Projekt, das in keiner Verbindung zu Nous Research steht und von Nous Research weder unterstützt noch gesponsert wird.

Ein Problem melden

Leg ein Issue auf GitHub an und schreib dazu:

  • die App-Version (unten in den Einstellungen) und die Systemversion deines Handys,
  • die Backend-Version und was npx hermes-ui status anzeigt,
  • was du gemacht hast, was du erwartet hast und was passiert ist; Screenshots helfen.

Niemals posten: Kopplungslinks, QR-Codes, Tokens oder den Inhalt von .env oder dem Datenverzeichnis des Backends – damit bekommt man Zugriff auf dein Backend.

Sicherheitslücken bitte vertraulich über die private Schwachstellenmeldung von GitHub melden.
